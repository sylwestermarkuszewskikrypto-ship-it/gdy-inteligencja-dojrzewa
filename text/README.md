# Machine-readable text editions

This directory contains Markdown editions of **Gdy inteligencja dojrzewa / When Intelligence Matures / Wenn Intelligenz reift** by Sylwester Markuszewski.

The purpose of these files is to make the text easier to read by humans, search tools, research software, and AI systems that may have difficulty extracting text from PDF files.

**The PDF editions in the repository remain the official publication editions.** If a discrepancy is introduced by text extraction or Markdown formatting, the corresponding PDF is authoritative.
